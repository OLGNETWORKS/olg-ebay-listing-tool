# OLG Listing Tool

Herramienta interna para diseñar, validar y publicar anuncios de eBay. El producto parte de un editor por bloques: el usuario edita JSON estructurado y el sistema genera HTML/CSS estático apto para la descripción del anuncio.

## Estado

El repositorio está en fase de fundación. La integración real con eBay queda detrás de adaptadores y bloqueos explícitos; mientras se aprueban las credenciales se desarrolla con mocks y fixtures locales.
